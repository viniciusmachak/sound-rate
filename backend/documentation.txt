=========================================
SOUNDRATE BACKEND API QUICK REFERENCE
=========================================

Base path:
  /api/v1

Authentication:
  Protected endpoints require:
    Authorization: Bearer <jwt>

Conventions:
  [PUBLIC]  No authentication required
  [AUTH]    Valid JWT required
  [OWNER]   Valid JWT required and caller must own the target resource

Pagination:
  Endpoints returning pages accept standard Spring pagination params:
    ?page=<number>
    ?size=<number>
    ?sort=<field>,<asc|desc>


========================
AUTH
========================

POST /api/v1/auth/register                         [PUBLIC]
  Purpose:
    Create a new user account and return a JWT.
  JSON body:
    {
      "username": "string, 3-50 chars",
      "email": "valid email",
      "password": "string, min 6 chars"
    }
  Success:
    201 Created
    Returns:
      {
        "token": "<jwt>",
        "user": {
          "id": number,
          "username": string,
          "avatarUrl": string
        }
      }
  Common errors:
    400 validation error
    409 username or email already in use

POST /api/v1/auth/login                            [PUBLIC]
  Purpose:
    Authenticate with username or email plus password.
  JSON body:
    {
      "username": "username or email",
      "password": "string"
    }
  Success:
    200 OK
    Returns auth payload with JWT and user summary.
  Common errors:
    401 invalid credentials or disabled account

POST /api/v1/auth/forgot-password                  [PUBLIC]
  Purpose:
    Start password-reset flow.
  JSON body:
    {
      "email": "valid email"
    }
  Success:
    200 OK
  Notes:
    Response does not reveal whether the email exists.

POST /api/v1/auth/reset-password                   [PUBLIC]
  Purpose:
    Finish password reset using a reset token.
  JSON body:
    {
      "token": "reset token",
      "newPassword": "string, min 6 chars"
    }
  Success:
    200 OK
  Common errors:
    400 invalid or expired token

DELETE /api/v1/users/me/avatar                     [AUTH]

========================
RATINGS
========================

POST /api/v1/ratings                               [AUTH]
  Purpose:
    Create or update an album or track rating.
  JSON body:
    {
      "albumId": "required",
      "trackId": "optional",
      "rating": "0.5 to 5.0"
    }
  Behavior:
    If trackId is present, the request updates a track rating and recalculates the
    user's album rating from track ratings.
    If trackId is absent, the request updates the album rating directly and clears
    track ratings for that album.
  Success:
    200 OK
  Common errors:
    400 validation error

GET /api/v1/ratings                                [AUTH]
  Purpose:
    Return the authenticated user's recent album and track ratings.
  Success:
    200 OK
    Returns:
      {
        "albumRatings": [...],
        "trackRatings": [...]
      }

DELETE /api/v1/ratings                             [AUTH]
  Purpose:
    Delete an album or track rating.
  Query params:
    albumId   optional
    trackId   optional
  Rules:
    At least one of albumId or trackId must be provided.
    If albumId is provided without trackId, album rating, review, and track ratings
    for that album are removed for the authenticated user.
  Success:
    204 No Content
  Common errors:
    400 when neither albumId nor trackId is provided

========================
ERROR RESPONSE SHAPE
========================

Typical error response:
  {
    "timestamp": "<ISO-8601 instant>",
    "status": 400,
    "error": "Bad Request",
    "message": "Human-readable summary",
    "path": "/api/v1/..."
  }

Validation errors may return:
  {
    "timestamp": "<ISO-8601 instant>",
    "status": 400,
    "error": "Validation Error",
    "path": "/api/v1/...",
    "errors": {
      "fieldName": "validation message"
    }
  }

Notes:
  - Protected endpoints return 401 when no valid JWT is provided.
  - Ownership violations return 403.
  - Internal errors are intentionally sanitized and do not expose stack traces.
